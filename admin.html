Panel admin belum dikonfigurasi

Kunci berikut belum diisi di Cloudflare:

  1. Buka Worker agrixentris di dashboard Cloudflare, lalu Settings → Variables and Secrets → Add.
  2. Tambahkan bertipe Secret: ADMIN_PASSWORD (kata sandi panel ini) dan GITHUB_TOKEN (fine-grained token dengan izin Contents: Read and write untuk repo situs).
  3. Klik Deploy, lalu muat ulang halaman ini.

Langkah lengkap ada di README repo.
